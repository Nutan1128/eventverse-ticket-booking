# LuminaPass - Premium Event Ticket Booking

LuminaPass is a premium, modern front-end web application for discovering and booking tickets for various events, including concerts, sports, movies, and festivals. It features a sleek dark UI, glassmorphism aesthetics, and a fully interactive user experience.

## 🚀 Features

- **Premium Dark UI**: Built with modern CSS variables, deep ambient backgrounds, and glassmorphism (backdrop filters).
- **Responsive Design**: Flawlessly adapts to all screen sizes (Desktop, Laptop, Tablet, and Mobile).
- **Dynamic Event Discovery**: Includes real-time search functionality and category filtering pills.
- **Interactive Event Cards**: View extra event details with smooth expand/collapse animations.
- **Seamless Booking Flow**: 
  - Comprehensive form validation for name, email, and ticket quantities.
  - Interactive standard and VIP tier selection.
  - Auto-navigation and auto-selection of events from the event cards.
- **"My Tickets" Digital Wallet**: 
  - An interactive, off-canvas drawer that stores successfully booked tickets.
  - Automatically generates mock barcodes for realism.
  - Allows users to easily cancel individual tickets, automatically updating their wallet state.
- **Accessibility**: Includes robust `:focus-visible` states for keyboard navigation.

## 🛠️ Tech Stack

- **HTML5**: Semantic and accessible document structure.
- **CSS3 (Vanilla)**: Advanced styling using Flexbox, CSS Grid, custom properties (variables), media queries, and smooth transitions.
- **JavaScript (Vanilla)**: Handles DOM manipulation, event listeners, form validation, dynamic ticket generation, and interactive components without relying on external libraries.

## 📂 Project Structure

- `index.html`: The main semantic structure and layout of the application.
- `style.css`: All styling rules, responsive media queries, and design system variables.
- `script.js`: Interactive logic (filtering, form validation, ticket drawer wallet).

## 💻 Getting Started

This is a pure front-end project with no build tools or backend dependencies required. 

1. Clone or download the repository to your local machine.
2. Open `index.html` directly in any modern web browser (Chrome, Firefox, Safari, Edge).
3. Browse events, test the search/filter functionality, and try booking a ticket to see the interactive digital wallet in action!
